# Extensions Bookmark 图标缓存规格

## 目标

书签列表启动和刷新时只读取本地图标，避免 TreeView 反复加载 Marketplace 远程 URL。

## 行为

- 图标文件存放在扩展 `globalStorage/icons/`。
- 缓存元数据存放在 `globalStorage/icon-cache.json`，不写入可同步的 `data.json`。
- 启动不等待网络；已有缓存立即显示，无缓存时先显示状态 ThemeIcon。
- 新增收藏后立即检查并缓存对应图标。
- 已收藏扩展安装、重装或版本变化时，优先从本地扩展目录更新缓存。
- 其他情况下，仅当上次检查已超过 7 天时后台刷新图标。
- 批量刷新使用最多 4 个并发 worker，兼顾首次缓存速度和连接数量。
- 同一批次只在完成后统一写一次缓存元数据。
- Marketplace 查询与图标下载各自最多等待 8 秒。
- 批量网络失败只写一条摘要日志，不向 Extension Host 输出逐项错误堆栈。
- 刷新失败时保留旧缓存，仅在当前会话内抑制重试；下次 Extension Host 重启后再次尝试。
- 已安装但未收藏的扩展继续直接使用其本地安装目录图标。

## 验收

- `buildIconPath` 不再返回 Marketplace HTTP(S) URL。
- 同一扩展未超过 7 天时不会再次发起图标网络检查。
- 失败项在当前会话内不重复请求，但下次重启会重新尝试。
- 收藏触发强制图标检查。
- 安装或版本变化触发本地图标更新。
- 缓存缺失或网络失败不阻塞插件激活及 TreeView 渲染。
